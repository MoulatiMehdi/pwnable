## solution 


the `rand()` function without using the `srand()` function  uses the same seed to randomize the the value of it. 
which  means when running the binary the same random integer value will be the same.

and since if :  

a `^` b == c <=> b `^` c == a  <=> c `^` a == b


which means we can find the exact input that will solve this puzzle. 

let : 
- `r` is the number generated by `rand()` function 
- `a` is the number that will solve the puzzle 

if `a` `^` `r` equal to `0xcafebabe` 
then `0xcafebabe` `^` `r` equal to  `a`



with is the solution to the problem.
